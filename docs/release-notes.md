# NetRedirector v1.7.3

## 更新下載大幅加速：智能分流 + 防呆

這一版重做了自動更新的下載路徑選擇。若你曾遇過「瀏覽器下載很順，但程式內建更新走走停停、速度一直歸零、要拖很久才完成」，本版即為此修正。

### 智能分流

下載更新前，程式會**並行實測**「直連」與「設定中的每一條代理」的實際吞吐（各抓 256 KB 實際資料計速，而非只量 ping 延遲），再挑**最快的一條**來下載。選路結果會寫入主視窗日誌，例如：

```
更新下載路徑: MyPhone (0.22 MB/s)
```

代理若在傳輸途中失敗，會自動改用次快的路徑，最後保底直連：

```
路徑「MyPhone」失敗，改用下一條: ...
更新下載路徑: 直連 (0.13 MB/s)
```

### 防呆（不會因為代理壞掉而更新失敗）

| 情境 | 行為 |
| --- | --- |
| 代理連不上 / 不支援 | 量測階段即略過，自動走其他路徑 |
| 代理中途斷線 | 自動改用下一條，最後保底直連 |
| 沒有設定任何代理 | 完全不量測，零額外延遲，行為與舊版相同 |
| `config.json` 不存在 / 損毀 / 非 JSON | 視為無代理，不拋出例外、不中斷更新 |

SOCKS5 一律以 `socks5h://` 連線（由代理端解析 DNS），避免本機 DNS 被轉址規則影響；代理密碼沿用既有的 DPAPI 加密存放機制，解密失敗時視為無密碼。

### 下載引擎改進

- **提高並行分段**：分段大小 4 MB → 1 MB、分段數上限 16 → 32，連線數隨檔案大小提升。
- **速度顯示平穩化**：GitHub 的 CDN 常以突發方式送資料，舊版用 0.5 秒瞬時速度估算，幾乎每個停頓窗都顯示 `0 B/s`（實測一個 32.7 MB 的下載出現 183/243 次歸零）。本版改用數秒滑動視窗平均，忠實反映實際吞吐。

實測同一條不穩定的線路，32.7 MB 的更新由 123 秒縮短至約 32 秒，速度歸零的顯示次數由 75% 降至 13%。

> 本加速由 v1.7.3 起的更新流程生效；也就是說，**之後**的版本更新才會享受到這套分流。
